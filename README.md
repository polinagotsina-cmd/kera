# KERA — coworking in Old Town, Tbilisi

A one-page website concept for KERA, a coworking space in Tbilisi.

Plain HTML, CSS and JavaScript — no frameworks, no build step.

- `index.html` — the page (hero, what's included, prices, footer, folder window)
- `css/style.css` — styles; colors, fonts and sizes as CSS variables at the top
- `js/main.js` — mobile menu, menu bar clock, folder window, photo viewer
- `assets/` — self-hosted Switzer font (Fontshare) and images

Design & code by [Polina Gotsina](https://polinagotsina-cmd.github.io/madebypolina/).
